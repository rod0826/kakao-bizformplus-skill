## Chrome 편집기에서 추가 확인한 사항

다음은 가이드 표와 별도로 2026-10-05 실제 제작 화면에서 관찰했다.

- 이벤트 제목은 20자 제한. 관리용 이름의 ‘수정’ 버튼과 이벤트 제목 입력란을 구분한다.
- 시작 페이지를 추가하면 제목 50자, 본문 300자, 법적 고지 명칭 40자 카운터가 표시된다. 이미지 사용과 URL 설정은 별도 옵션이다. 이미지 파일 조건은 업로드 창을 열어 확인한다. 관찰하지 않은 해상도·용량을 만들지 않는다.
- ‘답변 수정 제한’은 이전 문항으로 돌아가 답변을 바꾸는 것을 제한한다. 필요할 때만 켠다. 조건부 질문 분기나 중복 참여 방지 기능으로 해석하지 않는다.
- 객관식에는 ‘기타 보기 추가’와 ‘없음 보기 추가’가 있다. 일반 보기와 함께 선택 가능 방식 및 최대 개수를 현재 UI에서 확인한다.
- ‘문항 이동’으로 문항 순서를, 보기의 이동 제어로 보기 순서를 바꿀 수 있다. ‘문항 삭제’는 현재 편집 중인 항목 제거인지 확인한다.
- 동의문에 ‘카카오 참여형 광고 전환율 개선을 위한 정보 제공’ 옵션이 보였다. 도움말과 생성될 동의문, 실제 활용 목적을 확인한 뒤 사용자 요청과 일치할 때 사용한다. 이 옵션을 필수 수집·이용 동의나 광고주의 마케팅 동의와 동일하게 취급하지 않는다.
- 완료 페이지의 채널 상담 연결이 기본 ON이고 예시 연락처가 채워져 있었다. 상담을 쓰지 않으면 OFF로 바꾸고 예시 연락처를 제거·교체한다. 상담 안내 문구는 20자 제한이다.
- 미리보기는 Android 기준이며 OS마다 외형이 달라질 수 있다.

## 설계에서 입력까지

행사와 수집 목적을 먼저 정하고, 제목 → 시작 → 설문 → 정보 수집 → 동의 → 완료 페이지 순으로 내용을 채우면 검증하기 쉽다. 문항별 유형·필수·질문·설명·보기·숫자범위 또는 계층 데이터를 표로 먼저 정리한다.

계층형은 선택에 따라 하위 보기가 달라지는 구조다. 임의의 문항 이동/조건부 분기 기능이 있다고 가정하지 않는다. 엑셀은 해당 UI의 최신 샘플을 받아 열 이름·시트 구조를 보존하고 값만 작성한다. 샘플을 확보하지 못하면 수동 입력이나 설계안으로 진행한다.

전화번호/이메일은 플랫폼상 필수 수집 수단이다. 추첨 불참자의 연락처를 조건부로 제외하는 기능은 검증되지 않았다. 불참자에게도 수집되는 구조라면 그 사실을 알려 설계를 조정한다. 자유서술 문항에서 연락처를 중복 수집하지 않는다.

수집 목적·보유 기간·위탁·제공·국외 이전은 실제 처리 방식에 맞춘다. ‘없음’을 자동 선택하거나 업체를 추정하지 않는다. 템플릿 동의문을 법적 적합성 보증으로 설명하지 않는다. 업종별 법적고지가 필요한 경우 공식 가이드의 해당 업종 기준과 최신 심사 정책을 확인한다.

참여 기간이나 종료 제어는 현재 폼 UI에서 지원되는지 먼저 확인한다. 안내문에 기간을 쓰는 것만으로 자동 종료된다고 보고하지 않는다. 소재 연결·광고 운영 일정 설정은 사용자 요청 범위에서 별도로 수행한다.
