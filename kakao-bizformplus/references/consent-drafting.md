# 이벤트에 맞는 동의문 초안

## 이벤트부터 확인

대화에 이벤트 목적과 내용이 있으면 그대로 활용한다. 없으면 ‘어떤 이벤트를 진행하시나요? 참여 대상과 받은 정보를 어디에 사용할지도 알려주세요.’처럼 먼저 묻는다. 실운영 이벤트를 세미나로 추정하지 않는다. 행사 정보가 필요한 동의문 단계는 답변을 기다리되 확정 정보로 만들 수 있는 나머지 초안은 진행한다.

행사 내용이 없는 **순수 기능 테스트 요청**은 [세미나 테스트 예시](seminar-feedback.md)를 사용하고 실제 추첨·경품 지급·연락을 하지 않는 예시임을 알린다. 사용자가 쇼핑 이벤트 등 다른 테스트 주제를 지정하면 그 목적을 따른다. 테스트에서도 사업자 권한·수집 주체·보유 기간·위탁 여부를 임의로 확정하지 않는다.

## 필요한 운영 정보와 초안

이벤트에 필요한 값만 확인한다. 대화에서 이미 받은 내용은 다시 묻지 않는다.

- 이벤트 목적·대상, 실제 제공할 기능: 응모 접수, 후기 분석, 참석 확인, 상담 연락, 당첨 안내 등.
- 개인정보 수집 주체, 필요한 수집 항목과 항목별 사용 목적. 플랫폼의 연락처 필수 수집 조건도 설명한다.
- 이용·보유 기간과 파기 계획. 세미나 예시의 30일을 다른 이벤트에 자동 적용하지 않는다.
- 실제 위탁·제3자 제공·국외 이전 계획과 대상 업체, 채널 추가 등 선택 기능의 사용 여부.

확인된 정보를 `설정 항목 / 초안 / 확인이 필요한 값` 형태로 정리한다. 수집 목적 문구는 아래 구조를 참고해 실제 수행하는 내용만 넣는다.

|이벤트 예시|수집 목적 초안 예시|
|---|---|
|경품 응모|이벤트 응모 접수 및 당첨 안내|
|참석 신청|행사 참석 신청 접수 및 참석 안내|
|상담 신청|상담 신청 접수 및 요청한 상담 연락|
|후기 설문|행사 후기 수집 및 개선 의견 분석|

경품 배송이 실제로 필요한 경우에만 배송 목적·항목·처리 업체를 반영한다. 마케팅 동의를 응모·상담 동의에 자동으로 덧붙이지 않는다. 위 문구는 완성된 법적 동의문이 아니라 UI의 목적 필드에 들어갈 초안 예시다. 보유 기간은 확인된 운영 계획으로 별도 작성한다.

## 화면에 적용

카카오 UI가 제공하는 기본 동의문에는 확인된 수집 항목·목적·보유 기간과 필요한 확장 설정을 반영하고 생성된 참여자 동의문을 미리보기로 읽는다. ‘기타 동의문’은 기본 수집·이용 동의의 대체 수단으로 만들지 않으며 실제 필요한 추가 동의에만 사용한다. 필수/선택 구분과 UI 글자수 제한은 [creation.md](creation.md)를 따른다.

미확정 값은 검토용 초안에서 ‘미정’으로 표시한다. 순수 테스트의 보유 기간만 미확정이고 임시 저장을 진행할 때는 [검증 절차](verification.md)의 미정 표시 예외를 적용할 수 있다. 실운영·작성 완료 전에 실제 기간을 확정하며, 다른 필수 사실을 추정하거나 권한 확인을 대신하지 않는다. 초안의 적합성을 법적 보증으로 표현하지 않는다. 저장은 요청된 미저장/임시 저장/작성 완료 범위에서 수행한다.
