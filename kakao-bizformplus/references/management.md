## 실무 절차

목록의 필터·상태 선택·정렬·페이지를 이용해 원하는 폼을 찾는다. 같은 이름의 여러 폼이 있으면 ID와 수정일을 대조한다. 이름 클릭으로 폼 내용을 확인하고, 해당 행의 ‘관리’ 또는 ‘보고서’를 선택한다. 현재 화면의 상태 명칭은 ‘작성 완료’였다.

### 상세 설정

‘권한 설정’을 열어 대상 멤버별 현재 권한과 요청 변경을 비교한다. 권한을 바꾸기 전 대상 계정·권한 범위·개인정보 접근 효과를 명확히 한다. 민감정보 접근을 확대하는 최종 저장은 실행 환경의 확인 정책을 따른다. 기술적으로 가능한 권한 변경과 사용자 승인은 별개다.

‘알림톡 일정 변경’에서 요일, 시작·종료 시간, 주기를 설정한다. ON 대상 멤버가 없으면 일정만 저장해도 알림이 오지 않는다. 응답 완료 후 참여자에게 표시되는 연락 시간과 광고계정 멤버가 받는 신규응답 알림 일정을 구분한다. 설정 변경 성공은 새 일정 표시로 확인하며 실제 응답을 만들어 검증하지 않는다.

랜딩 URL은 실제 입력란의 값을 가져온다. 링크 읽기와 외부 배포를 구분한다. 공개 공유가 요청된 경우에만 해당 채널에 배포한다. 링크 응답의 폼 단위 합산을 캠페인별 성과로 오해하지 않는다.

### 보고서

‘폼 보고서’에서 다운로드 가능 여부와 권한을 확인한다. ‘파일 비밀번호 설정’만 보이면 암호 미설정 상태다. 암호 설정/재설정은 사용자가 직접 입력·확정하도록 맡긴다. 파일 암호를 채팅·로그·저장소에 남기지 않는다.

사용자가 다운로드를 요청하면 필요한 보고서만 내려받고 파일 존재·형식·조회 범위를 확인한다. 다운로드 실패 시 권한 → 암호 → 수집 데이터/기간 → 다운로드 알림 순으로 확인한다. 암호화 ZIP 해제 실패는 다운로드 실패와 구분한다.

플랫폼의 90일 만료와 광고주가 동의문에 정한 보유 기간은 별개다. 더 짧은 보유 기간을 정했다면 광고주가 보유한 내보내기 파일과 연동 시스템도 그 기간에 맞게 처리해야 한다. 동의문을 입력했다고 실제 삭제 작업이나 자동화가 설정되었다고 보고하지 않는다.

### 변경 이력·삭제

변경 이력에서 분류·변경 내용·일시를 확인한다. 공식 가이드에 없는 이전 이력 조회 방법을 만들지 않는다.

삭제는 정확한 ID, 연결 소재 수, 응답 수를 확인하고 복구 불가임을 설명한 뒤 최종 동작 직전에 확인받는다. 삭제가 비활성이라면 사유를 보고한다. 삭제 가능 상태를 만들 목적으로 연결 소재나 응답을 지우지 않는다. 완료 폼을 고치려는 요청이면 기존 폼은 유지하고 새 폼 제작을 제안·수행한다.
